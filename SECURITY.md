# Security policy

## Supported versions

Only the latest release receives security fixes. Please update to the newest version before reporting a problem.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Include what you found, how to reproduce it and which version you tested. You will get a response in the advisory thread.

## Scope

This policy covers the code in this repository. Installations that other people host themselves, and the servers they run on, are outside its scope.
